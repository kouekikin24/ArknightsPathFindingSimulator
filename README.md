# 明日方舟寻路模拟器

Java 21 + Swing 的桌面寻路模拟器。可编辑地图和路线，逐帧查看单位移动轨迹。

## 环境

- Windows
- Java 21（`java`、`javac` 可在命令行使用）
- 界面皮肤依赖 `lib/flatlaf.jar`（已随仓库附带，脚本自动加入类路径）

## 启动

双击或在项目目录运行以下任一命令：

```bat
run-ui.cmd
```

```powershell
powershell -ExecutionPolicy Bypass -File .\run-ui.ps1
```

界面会自动编译并启动。首次打开时，地图以 `100%` 适应可视区域。

## 编辑地图

右侧“编辑”区域选择工具后，在地图上左键点击或拖动：

- 通路、箱子、坑、墙：修改地形。
- `S`：设置起点。
- `E`：设置终点。
- `+`：按右侧检查点面板选中的类型，在地图上放置坐标类检查点（移动、巡逻、传送出现）。

右侧“检查点”区域可编辑全部检查点类型。“新建”和“示例”会重置当前地图与模拟状态。

## 多单位

右侧“单位”区域管理路线列表，每条路线对应一个敌人：

- `添加`：复制当前路线为新单位，随后在列表中选择单位即可单独编辑它的起点、终点、检查点和移动参数。
- `删除`：移除选中的单位（至少保留一个）。
- 地图编辑和战斗状态注入都作用于当前选中的单位；地形是所有单位共享的。
- 每个单位用不同颜色绘制轨迹和实体；轨迹悬停提示会标注单位编号。
- 当所有单位都到达完成或阻挡状态时，模拟进入终态。

## 编辑检查点

右侧“检查点”区域支持核心的全部检查点类型：

- “类型”下拉选择种类，“参数”输入秒数或区块号（坐标类无需参数）。
- 坐标类（移动、巡逻、传送出现）用 `+` 工具在地图上放置；按住 `Shift` 点击则吸附到格子中心。
- 非坐标类（等待、消失、警报等）用“添加”按钮加入列表；选中某项时插入到它之前，未选中则加到末尾。
- “更新”把选中的检查点改为当前类型和参数；“上移”“下移”调整顺序；“删除”“清空”移除。
- 路由规则会在修改时校验：例如“消失”之后必须紧跟“传送出现”才能继续移动。违反规则的修改会被拒绝，并在底部状态栏说明原因。
- 巡逻回环：最后一个检查点是“巡逻”且目标不同于第一个检查点时，走完会回到第一个检查点循环。
- 列表始终保留一个选中行，“更新”直接作用于它；坐标支持四位小数，中文输入法打出的全角数字和句号（。）会自动转换。

## 反馈问题时：组件编号

每个可交互组件都有稳定编号。**按住 Ctrl 约 0.2 秒，把鼠标悬停在任何控件上**，会弹出它的编号和中文名（例如 `C2 · 检查点坐标 Y`）。报告问题时带上编号即可零歧义定位。完整编号清单见 [docs/component-map.md](docs/component-map.md)。

## 主题

工具栏右侧的主题按钮在三档之间循环：**跟随系统**（图标"自"，读取 Windows 的应用深浅色设置）、**白天**（☾）、**黑夜**（☀）。黑夜模式使用 Darcula 色板，所有控件（含滚动条、下拉框）都是深色。

## 撤销与快捷键

- 工具栏 `↶` / `↷` 撤销、重做场景编辑；快捷键 `Ctrl+Z`、`Ctrl+Y`（或 `Ctrl+Shift+Z`）。
- 可撤销的编辑包括：地形、起点/终点、检查点、移动设置、单位增删、新建/示例/导入。战斗注入与回放进度属于运行状态，不可撤销；撤销或重做会像任何场景编辑一样从第 0 帧重新开始。
- 撤销历史最多保留 100 步；撤销之后做了新编辑，重做分支会被清空。
- `Delete`（或 `BackSpace`）删除选中的检查点；`Esc` 暂停播放。
- `Ctrl+0` 复位视图到适应全图；`Ctrl+=` / `Ctrl+-` 以视图中心缩放。
- 检查点面板的输入框里按 `回车` 等于点"更新"。
- 时间轴滑块获得焦点时（默认就是它）：`←`/`→` 逐帧、`PgUp`/`PgDn` 十帧、`Home`/`End` 首末帧。

## 战斗状态

右侧“战斗状态”区域可注入三种状态（均从下一帧起生效）：

- `眩晕`：单位原地不动指定秒数（取整到帧），到期自动恢复移动。
- `击退`：以给定速度（格/秒）推动指定秒数，期间地形碰撞仍然生效，到期恢复自动寻路。
- `束缚`：开关切换，束缚期间单位不移动，解除后继续。

注入以帧事件形式记录，回放与时间轴拖动会按帧重放，确定性不受影响。如果先回退到较早的帧再注入，注入点之后已生成的帧会被丢弃，从注入点起重新生成。模拟到达终态后无法注入。

## 浏览与缩放

- 选择右侧的“浏览”工具后，按住左键拖动地图；任意工具下按住右键拖动也可以平移。
- 拖动距离按屏幕像素 1:1 平移，放大地图后不会变快。
- 鼠标滚轮直接缩放，并以鼠标位置为中心；按住 `Shift` 滚轮则上下滚动。
- 可用滚动条查看放大后的地图。
- 最大缩放为 `30000%`。

切换回任意编辑工具即可继续修改地图。

## 运行与回放

- 顶部 `▶` 开始或暂停模拟；单步按钮推进一帧；重置按钮回到初始状态。
- 回放倍率可选择 `1x`、`3x` 或 `10x`。
- 底部时间轴按帧拖动，可查看已生成的任意帧。
- 时间输入框可输入帧号，例如 `16`；也可输入 `16/30`、`0.5`、`1.2`。输入后点击“定位”或按 Enter。
- 不能对应完整帧的时间会显示错误，不会自动取整。
- 模拟到达完成或阻挡状态后，不能跳转到更晚的帧。

界面同时显示当前帧号和时间。时间轴的第 `0` 帧是初始状态。

## 查看轨迹

- “实际轨迹”默认开启，红线显示已生成的单位实际移动轨迹。
- “路线图”默认关闭，需要时可在顶部手动开启。
- 模拟开始后，起点和检查点标记会隐藏，方便观察红线。
- 鼠标靠近红线时，会在最近的真实轨迹点标出一个小红点，并在鼠标旁显示该点的帧号和坐标。
- 传送、消失或出现位置之间不会画连接线。

## 导入与导出

顶部工具栏提供三个按钮：

- `导出场景`：把当前地图、所有路线和移动设置保存为文本文件（UTF-8）。
- `导入场景`：从上述文本文件恢复场景。文件内容非法时会在底部状态栏显示具体行号的错误，且当前场景保持不变。
- `导出轨迹`：把每个单位已生成的每一帧导出为 CSV（单位号、帧号、模式、检查点、位置、速度、避障、事件），可直接用表格软件或脚本处理。

场景文件是逐行键值文本，可手工编辑；每个 `unit` 块是一条路线：

```text
map 12 8
unit 1
spawn 1 1
endpoint 10 6
movement GROUND
speed 1.0
diagonal true
checkpoint MOVE 5 1
unit 2
spawn 1 2
endpoint 10 6
movement FLYING
speed 2.0
diagonal false
terrain 7 3 BOX
```

只列出非通路的格子；`#` 开头的行是注释；地图边长范围是 `2` 到 `512`。旧版单单位文件（没有 `unit` 行）仍可导入。

## 运行验证

在项目目录依次运行：

```bat
run-tests.cmd
```

```powershell
powershell -ExecutionPolicy Bypass -File .\run-tests.ps1
```

```bat
run-ui.cmd --verify
```

```powershell
powershell -ExecutionPolicy Bypass -File .\run-ui.ps1 --verify
```

`run-smoke.cmd` 另有一个桌面冒烟测试：打开真实窗口，用 `java.awt.Robot` 自动画墙、撤销/重做、播放、定位、注入并逐步截图（`smoke-shots/`）。它会接管鼠标键盘约 20 秒，运行期间不要操作电脑；无桌面会话（如 CI）无法运行。

也可以检查提交前的空白错误：

```powershell
git diff --check
```
