# 明日方舟寻路模拟器

Java 21 + Swing 的桌面寻路模拟器。可编辑地图和路线，逐帧查看单位移动轨迹。

## 环境

- Windows
- Java 21（`java`、`javac` 可在命令行使用）

## 启动

双击或在项目目录运行以下任一命令：

```bat
run-ui.cmd
```

```powershell
powershell -ExecutionPolicy Bypass -File .\run-ui.ps1
```

界面会自动编译并启动。首次打开时，地图以 `100%` 适应可视区域。

## 编辑地图

右侧“编辑”区域选择工具后，在地图上左键点击或拖动：

- 通路、箱子、坑、墙：修改地形。
- `S`：设置起点。
- `E`：设置终点。
- `+`：按右侧检查点面板选中的类型，在地图上放置坐标类检查点（移动、巡逻、传送出现）。

右侧“检查点”区域可编辑全部检查点类型。“新建”和“示例”会重置当前地图与模拟状态。

## 编辑检查点

右侧“检查点”区域支持核心的全部检查点类型：

- “类型”下拉选择种类，“参数”输入秒数或区块号（坐标类无需参数）。
- 坐标类（移动、巡逻、传送出现）用 `+` 工具在地图上放置。
- 非坐标类（等待、消失、警报等）用“添加”按钮加入列表；选中某项时插入到它之前，未选中则加到末尾。
- “更新”把选中的检查点改为当前类型和参数；“上移”“下移”调整顺序；“删除”“清空”移除。
- 路由规则会在修改时校验：例如“消失”之后必须紧跟“传送出现”才能继续移动。违反规则的修改会被拒绝，并在底部状态栏说明原因。
- 巡逻回环：最后一个检查点是“巡逻”且目标不同于第一个检查点时，走完会回到第一个检查点循环。

## 战斗状态

右侧“战斗状态”区域可注入三种状态（均从下一帧起生效）：

- `眩晕`：单位原地不动指定秒数（取整到帧），到期自动恢复移动。
- `击退`：以给定速度（格/秒）推动指定秒数，期间地形碰撞仍然生效，到期恢复自动寻路。
- `束缚`：开关切换，束缚期间单位不移动，解除后继续。

注入以帧事件形式记录，回放与时间轴拖动会按帧重放，确定性不受影响。模拟到达终态后无法注入。

## 浏览与缩放

- 选择右侧的“浏览”工具后，按住左键拖动地图。
- 拖动距离按屏幕像素 1:1 平移，放大地图后不会变快。
- 鼠标滚轮直接缩放，并以鼠标位置为中心。
- 可用滚动条查看放大后的地图。
- 最大缩放为 `30000%`。

切换回任意编辑工具即可继续修改地图。

## 运行与回放

- 顶部 `▶` 开始或暂停模拟；单步按钮推进一帧；重置按钮回到初始状态。
- 回放倍率可选择 `1x`、`3x` 或 `10x`。
- 底部时间轴按帧拖动，可查看已生成的任意帧。
- 时间输入框可输入帧号，例如 `16`；也可输入 `16/30`、`0.5`、`1.2`。输入后点击“定位”或按 Enter。
- 不能对应完整帧的时间会显示错误，不会自动取整。
- 模拟到达完成或阻挡状态后，不能跳转到更晚的帧。

界面同时显示当前帧号和时间。时间轴的第 `0` 帧是初始状态。

## 查看轨迹

- “实际轨迹”默认开启，红线显示已生成的单位实际移动轨迹。
- “路线图”默认关闭，需要时可在顶部手动开启。
- 模拟开始后，起点和检查点标记会隐藏，方便观察红线。
- 鼠标靠近红线时，会在最近的真实轨迹点标出一个小红点，并在鼠标旁显示该点的帧号和坐标。
- 传送、消失或出现位置之间不会画连接线。

## 导入与导出

顶部工具栏提供三个按钮：

- `导出场景`：把当前地图、起终点、检查点和移动设置保存为文本文件（UTF-8）。
- `导入场景`：从上述文本文件恢复场景。文件内容非法时会在底部状态栏显示具体行号的错误，且当前场景保持不变。
- `导出轨迹`：把已生成的每一帧导出为 CSV（帧号、模式、检查点、位置、速度、避障、事件），可直接用表格软件或脚本处理。

场景文件是逐行键值文本，可手工编辑：

```text
map 12 8
spawn 1 1
endpoint 10 6
movement GROUND
speed 1.0
diagonal true
checkpoint 5 1
terrain 7 3 BOX
```

只列出非通路的格子；`#` 开头的行是注释。地图边长范围是 `2` 到 `512`。
